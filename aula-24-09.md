# CLIENTE VS SERVIDOR
**Cliente** *é quem faz o pedido (Request)*
**Servidor** *É quem recebe o pedido e entrega uma resposta. (Response)*


       Você
        ↓
Chrome (CLIENTE)
        ↓  
"Quero acessar o site X"
        ↓
    SERVIDOR
        ↓  
"Aqui está o site"
        ↓
     Chrome
        ↓
  Você vê o site

## Protocolos
* Um protocolo é um conjunto de regras para duas partes conseguirem se comunicar.

* Na internet:
Cliente 🤝 Servidor
precisam seguir um protocolo para se entender.

*Protocolo = regras de comunicação*
*HTTP = regras usadas para comunicação na Web*

CLIENTE
"Me envie esta página"
       ↓
      HTTP
       ↓
    SERVIDOR
"Aqui está a página"

## encapsulamento (como a informação navega na internet)
Encapsulamento é basicamente uma forma de colocar uma informação dentro de outra, seguindo as regras de cada camada da comunicação.
------------------------------------
Pense em uma encomenda 📦:
Mensagem
  ↓
[ HTTP ]
  ↓
[ TCP ]
  ↓
[ IP ]
  ↓
[ Ethernet/Wi-Fi ]
  ↓
Rede
-----------------------------------
Cada camada embrulha a camada anterior.

E no servidor acontece o contrário: ele desencapsula, retirando as informações de cada camada até chegar à mensagem original.
--------------------------------------------

## http  vs https 

HTTP *É o protocolo usado para comunicação entre cliente e servidor, mas sem criptografia.*
- Se alguém conseguir interceptar a comunicação, os dados podem ser lidos.

HTTPS *É o HTTP com uma camada de segurança (TLS).*

**Cliente → HTTPS 🔒 → Servidor**
- Os dados são criptografados durante o transporte, dificultando que terceiros leiam ou alterem a comunicação.
.
----------------------------------------------
Porta padrão HTTP:80
Porta padrão HTTPS:443

HTTPS = *HTTP* + *segurança (TLS) 🔒*
-
------------------------------------------

## URL
**URL é o endereço de um recurso na Web.**

*Pense nela como o endereço de uma casa 🏠.*

Exemplo: https://www.exemplo.com/produtos/celular

Podemos separar:

https://            → protocolo ou schema
www                 → subdomínio
exemplo.com         → domínio ou servidor
/produtos/celular   → caminho ou recurso
---------------------
**hoje em dia o www não se faz mais necessário:**
Antigamente → *www era muito comum para identificar o servidor Web.*
Hoje → *o domínio principal pode fazer isso sozinho.*

## Portas

*Uma porta é como uma "entrada numerada" em um computador que permite identificar qual serviço deve receber uma comunicação.*

Imagine um prédio:

🏢 Computador
│
├── 🚪 Porta 80   → HTTP
├── 🚪 Porta 443  → HTTPS
├── 🚪 Porta 22   → SSH
└── 🚪 Porta 25   → SMTP

**Quando chega uma comunicação, o computador olha:**

*"Qual porta?"*

**E encaminha para o serviço correspondente.**

🌐 Exemplo

Quando você acessa:

https://google.com

o navegador usa HTTPS, que normalmente utiliza a:

🚪 Porta 443

Já:

http://exemplo.com

normalmente usa:

🚪 Porta 80
----------------------------------------------
🧠 Não confunda

IP        → identifica qual computador 📍
Porta     → identifica qual serviço naquele computador 🚪
Protocolo → define as regras da comunicação 📜
-----------------------------------------------
**Uma analogia boa:**

IP = *endereço do prédio*
Porta = *número da sala*
Protocolo = *regras para conversar*

.

## Métodos HTTP
*São ações que o cliente pede ao servidor para realizar.*

**Cliente → HTTP → método → servidor → resposta.**
-----------------------------------------------------------------------
Os principais métodos são:

GET	    → Buscar
POST	  → Criar/enviar	
PUT	    → Substituir/atualizar	
PATCH	  → Alterar parcialmente	
DELETE	→ Excluir	
.
