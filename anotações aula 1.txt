Tipos de dados podem ser :

* Primitivos: Primitivo guarda um valor simples
* Complexos:  Pode guardar uma coleção/estrutura de valores e comportamentos.

** TIPOS PRIMITIVOS

string	-> "Olá" - ("",'',``)
number	-> 42, 3.14
boolean	-> true, false
undefined → "não foi definido"
null      → "foi definido como vazio"

** explicação undefined e null **

undefined -> undefined (uma variável foi declarada, mas ainda não recebeu um valor.)
** Pense em undefined como: "Não foi definido nenhum valor."
-
null	-> null (é um valor que você atribui propositalmente para indicar que não existe nenhum valor.)
** Pense em null como: "Eu defini que não existe um valor aqui."

--

#Exemplos:

const nome = "Marcos";      // string
const idade = 30;           // number
const ativo = true;         // boolean
let valor;                  // undefined
const vazio = null;         // null
